# 📊 FinTrack V2

FinTrack is a full-stack personal finance and expense management application built using Node.js, Express, MySQL, React, and JWT authentication.

## 🚀 Features

### 🔐 Authentication
- User Registration & Login
- JWT-based authentication
- Protected routes

### 👤 Role-Based Access
- Users and Admin roles
- Admin-only route to create users
- Secure middleware-based access control

### 💰 Expense Management
- Add income & expense transactions
- Update and delete transactions
- Payment method tracking (UPI, cash, card, etc.)

### 📊 Dashboard
- Total income
- Total expenses
- Balance calculation

---

## 🛠️ Tech Stack

**Frontend**
- React (Vite)
- Bootstrap
- Axios
- Context API

**Backend**
- Node.js
- Express.js
- MySQL
- JWT Authentication
- bcryptjs
